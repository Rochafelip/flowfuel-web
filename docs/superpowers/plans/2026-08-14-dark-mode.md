# Dark Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let the user choose Light, Dark, or System theme (Profile screen), persisted per device, applied across the whole app.

**Architecture:** Tailwind's `class`-strategy dark mode + a `ThemeContext` (mirrors `AuthContext`'s style) that resolves the effective theme, toggles the `dark` class on `<html>`, and persists the choice to `localStorage`. Every file with hardcoded light-mode color classes gets the matching `dark:` companion class added, following one canonical conversion table (below) — no new abstraction layer, just additive Tailwind classes, consistent with how this codebase already composes styles.

**Tech Stack:** React 19, TypeScript (strict), Tailwind CSS (`darkMode: 'class'`). No test framework in this repo — verification is `npx tsc -b` after each task, plus a `grep` count check proving every listed class got its dark companion, and `npm run build` at the end.

**Variant rule:** if the occurrence has a prefix (`hover:X`, `active:X`, `lg:X`), the add-class also gets that prefix inserted right after `dark:` — e.g. `hover:bg-gray-50` → add `dark:hover:bg-gray-700`; `active:bg-gray-100` → add `dark:active:bg-gray-700`; `lg:bg-white` → add `dark:lg:bg-gray-800`.

**Exception:** `hover:bg-green-50` (the subtle brand-tinted hover on nav items/links) → add `dark:hover:bg-gray-950` instead of a green shade (keeps it a neutral, barely-there hover on dark backgrounds — a green-950 tint there read as muddy in review, gray-950 reads as a clean "pressed" state).

**Never changed** (already have sufficient contrast in both themes — do not touch): `bg-green-600`/`bg-green-700`/`bg-green-800`, `bg-red-600`/`bg-red-700`/`bg-red-800`, `border-green-500`/`border-green-600`, `text-white`, `bg-black/40`, `focus-visible:outline-*`, any emoji/icon.

### Task 2: `ThemeContext.tsx` — theme state and persistence

**Files:**
- Create: `src/context/ThemeContext.tsx`

- [ ] **Step 1: Create the file**

```tsx
import { createContext, useContext, useEffect, useState, type ReactNode } from 'react'

type Theme = 'light' | 'dark' | 'system'
type ResolvedTheme = 'light' | 'dark'

interface ThemeContextData {
  theme: Theme
  resolvedTheme: ResolvedTheme
  setTheme: (theme: Theme) => void
}

const STORAGE_KEY = '@theme_preference'

const ThemeContext = createContext<ThemeContextData>({} as ThemeContextData)

function getSystemTheme(): ResolvedTheme {
  return window.matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light'
}

function loadStoredTheme(): Theme {
  const stored = localStorage.getItem(STORAGE_KEY)
  return stored === 'light' || stored === 'dark' || stored === 'system' ? stored : 'system'
}

export function ThemeProvider({ children }: { children: ReactNode }) {
  const [theme, setThemeState] = useState<Theme>(loadStoredTheme)
  const [resolvedTheme, setResolvedTheme] = useState<ResolvedTheme>(() =>
    theme === 'system' ? getSystemTheme() : theme
  )

  useEffect(() => {
    if (theme !== 'system') {
      setResolvedTheme(theme)
      return
    }

    setResolvedTheme(getSystemTheme())

    const media = window.matchMedia('(prefers-color-scheme: dark)')
    function handleChange() {
      setResolvedTheme(getSystemTheme())
    }
    media.addEventListener('change', handleChange)
    return () => media.removeEventListener('change', handleChange)
  }, [theme])

  useEffect(() => {
    document.documentElement.classList.toggle('dark', resolvedTheme === 'dark')
  }, [resolvedTheme])

  function setTheme(newTheme: Theme) {
    localStorage.setItem(STORAGE_KEY, newTheme)
    setThemeState(newTheme)
  }

  return (
    <ThemeContext.Provider value={{ theme, resolvedTheme, setTheme }}>
      {children}
    </ThemeContext.Provider>
  )
}

export function useTheme() {
  return useContext(ThemeContext)
}
```

function AppearanceCard() {
  const { theme, setTheme } = useTheme()
  const options: { value: 'light' | 'dark' | 'system'; label: string }[] = [
    { value: 'light', label: 'Claro' },
    { value: 'dark', label: 'Escuro' },
    { value: 'system', label: 'Sistema' },
  ]

  return (
    <div className="flex flex-col gap-3 rounded-xl bg-white p-4 shadow-sm dark:bg-gray-800">
      <p className="text-sm font-bold text-gray-700 dark:text-gray-300">Aparência</p>
      <div className="flex rounded-lg border border-gray-300 p-1 dark:border-gray-600">
        {options.map((option) => (
          <button
            key={option.value}
            type="button"
            onClick={() => setTheme(option.value)}
            className={`flex-1 rounded-md py-2 text-sm font-bold transition-colors ${
              theme === option.value
                ? 'bg-green-600 text-white'
                : 'text-gray-600 dark:text-gray-400'
            }`}
          >
            {option.label}
          </button>
        ))}
      </div>
    </div>
  )
}
