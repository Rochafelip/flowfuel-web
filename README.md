# flowfuel-frontend

Web frontend for FlowFuel, built with Vite, React and TypeScript.

## Get started

1. Install dependencies

   ```bash
   npm install
   ```

2. Set the API URL (optional — defaults to production, `https://flowfuel-api.fly.dev`)

   ```bash
   cp .env.example .env
   ```

3. Start the dev server

   ```bash
   npm run dev
   ```

## Build

```bash
npm run build
```
